# SonarQube Lab

Educational Spring Boot project for studying SonarQube and static code analysis.

## Technology Stack

- Java 21
- Spring Boot 4.1.1
- Maven
- SonarQube
- Docker
- Docker Compose

## Purpose

This project is a laboratory for studying:

- static code analysis;
- code smells;
- bugs;
- vulnerabilities;
- security hotspots;
- test coverage;
- quality profiles;
- quality gates;
- SonarQube integration with Maven.

## Run SonarQube

Start SonarQube with:

```bash
docker compose up -d
